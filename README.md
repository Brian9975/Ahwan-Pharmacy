# Ahwan Pharmacy Website

A responsive pharmacy website built for **Ahwan Pharmacy Limited** using HTML, CSS, and vanilla JavaScript.

The website helps customers explore pharmacy services, browse essential products, submit prescriptions, and place inquiries or orders directly through WhatsApp.

## Live Website

https://ahwanpharmacy.co.ke

## Features

- **Responsive Design:** Optimized for mobile phones, tablets, and desktops.
- **Services Section:** Displays the pharmacy's available services.
- **Essentials Section:** Showcases essential pharmacy products with WhatsApp ordering options.
- **WhatsApp Ordering:** Allows customers to inquire about products and services using prefilled WhatsApp messages.
- **Prescription Submission:** Enables customers to send prescriptions directly to the pharmacy through WhatsApp.
- **Quick Contact Buttons:** Fixed WhatsApp and direct call buttons for convenient communication.

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)

## Project Impact

Since the website launched, Ahwan Pharmacy has reported receiving **11 online inquiries**, demonstrating its role as an additional digital channel for customer engagement.

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Brian9975/Ahwan-Pharmacy.git
```

### 2. Navigate to the Project Directory

```bash
cd Ahwan-Pharmacy
```

### 3. Run the Website

Open `index.html` in your preferred web browser.

No additional dependencies, environment variables, or configuration are required.
